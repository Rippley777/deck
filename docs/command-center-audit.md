Deck uses npm, React 19, TypeScript, Vite, Zustand, shared Zod validation and document persistence. Local storage requires no account. Cloud routes derive identity from Better Auth or hashed desktop credentials, guard origins/account switches, and use parameterized queries. There is no job framework or AI provider. House Edge browser telemetry exists; Running Tab and Black Box are documented relationships, not implemented adapters. No Codex integration exists. Portal and analytics environment flags are the existing feature gates. Existing formatter is Prettier; no JavaScript lint command/configuration exists.

Pit Boss currently exposes local Tauri IPC only, with command approval enforced in Rust. Its browser build simulates operations. Inventing a URL scheme or calling its internal runner from Deck would not be a working integration. This is a concrete external contract blocker for live action discovery/execution, not a blocker for the dashboard or GitHub work.
